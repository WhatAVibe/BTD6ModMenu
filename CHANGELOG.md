# Changelog

## 1.0.0

First public release as **BTD6 Mod Menu**.

- In-game menu (default **Insert**, rebindable) with Insta Monkeys, Powers, Sandbox, Towers,
  Unlocks, Resources and Help tabs.
- Insta monkeys for every base tower, including Skywarden, Mermonkey and Desperado.
  - 64 valid variants per tower.
  - Per-tower quantity overrides, Give/Set/Exact modes, saved between sessions.
- Powers: give/set every power, including Pro and event powers; unlock Powers Pro tiers.
- Resources: monkey money, tower XP, trophies, monkey knowledge and trophy store items.
- Account unlocks: towers, heroes, upgrades and paragons; knowledge refund.
- Sandbox: infinite cash/lives, no cooldowns, freeze towers, place anywhere, tower count and
  unlimited 5th-tier options, free purchases, damage multiplier, game speed, round controls,
  bloon spawning/clearing, win/defeat and sell-all.
- Tower editor: range, damage, attack speed, pierce, pops and paragon degree, with buff tags and
  automatic reapplication after upgrades.
- Full in-match hero switching using the In-Game Hero Switch approach.
- Credits for BTD6 Mod Helper, btd6-unlocker, InGameHeroSwitch, FasterForward and
  Unlimited5thTiers.
